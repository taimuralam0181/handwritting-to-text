Base URL:
http://127.0.0.1:8000

Authorization: Bearer YOUR_TOKEN


1. REGISTER
-----------

Content-Type: application/json

Body:

  "email": "user@example.com",
  "password": "strong-password-123"
}


2. LOGIN
--------

Body:

  "username": "taimur",
  "password": "strong-password-123"
}

Response:
{
  "token": "...",
  "expires_in": 2592000,
  "user": {
    "id": 1,
    "username": "taimur",

3. OCR IMAGE UPLOAD
-------------------

POST /api/ocr/
Authorization: Bearer YOUR_TOKEN
Content-Type: multipart/form-data

Form fields:
- image: required image file
- title: optional
- extraction_mode: both, crop, or full
- target_type: auto, mixed, word, line, or page

Example curl:

curl -X POST http://127.0.0.1:8000/api/ocr/ ^
  -H "Authorization: Bearer YOUR_TOKEN" ^
  -F "image=@C:\path\handwriting.jpg" ^
  -F "target_type=auto" ^
  -F "extraction_mode=both"

Response:
{
  "id": 15,
  "title": "",
  "image_url": "http://127.0.0.1:8000/media/uploaded_images/handwriting.jpg",
  "ocr_engine": "smart",
  "prediction_source": "local",
  "prediction_notes": "Auto-detected target type: page.",
  "raw_ocr_text": "...",
  "predicted_text": "...",
  "user_corrected_text": "",
  "correction_applied": false,
  "added_to_training_set": false,
  "uploaded_at": "2026-06-10T...",
  "target_type": "page",
  "used_saved_correction": false
}

9. COMMON ERROR STATUS
----------------------

400 = Invalid body/form/image
401 = Token missing, invalid, or expired
403 = Admin permission required
404 = Upload not found
409 = Username exists or training already running
